# Changelog

## v0.2.0 - 2026-11-12

- New Book view: press 4, or pick Layout > Book. Layout is now Single, Double, Book or Strip.
- Pages flip like a book when Page turn is set to Animated.
- Book look with a spine and page edges.
- PDFs with portrait pages open as a book.
- Page turns are no longer cut short when new pages load.
- PDF pages load at the size they are shown.
- The exe's file properties now show the right name, Gettic's Comic-Manga reader.
- Build paths are no longer stored inside the exe.

## v0.1.0 - 2026-11-11

- Opens comics from CBZ, CBR, CB7 and PDF files, and from folders of images.
- Single page, double page and strip (scroll) view modes.
- Right-to-left mode for manga.
- Fit and zoom options.
- Long vertical comics (webtoons) are detected automatically.
- Remembers the page and view for each comic, with a recent comics list.
- Open a comic from Explorer, by drag-and-drop or with the file picker.

## v0.0.1 - 2026-11-11

- First version: the project is set up.
- Opens an empty window (no features yet).
- Portable .exe, no installer needed.
